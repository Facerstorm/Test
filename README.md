# ВебДемо

Портфоліо вебдизайнера: послуги, три демонстраційні проєкти та форма для завантаження брифу.

Сайт: https://facerstorm.github.io/Test/

Сайт працює без збірки: `index.html`, `styles.css`, `studio-art.png` і папка `fonts/`.
Дані форми залишаються на пристрої відвідувача; бриф зберігається як текстовий файл.

Для GitHub Pages використовуйте гілку `main` і папку `/ (root)`.
